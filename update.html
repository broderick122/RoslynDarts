Update the scores

Keep using the same Excel file. Choose it here, check the preview, and publish. The site reads the scores in this browser and saves only those scores. It does not upload the spreadsheet, and it never reads the Capt. tab.

  1. 1. Save a GitHub token on this phone

    On GitHub, open Settings, then Developer settings, then Fine-grained tokens. Create a token that can access only the RoslynDarts repository, with Contents set to Read and write. Paste it here once. It stays in this browser and is not part of the website.

  2. 2. Choose the workbook

    Use the .xlsx you update during the season. Save it in Excel first so the calculated averages are stored in the file.

  3. 3. Publish

    Publishing writes data/league.json and data/league.js on the main branch of broderick122/RoslynDarts. That is the branch GitHub Pages serves.
